# ML Group 11 – 90-Day Repeat Purchase Prediction
## Contents of the zip:

```
ML_Group_11_notebook/
├── README.md
├── environment.yml
├── notebooks/
│   └── Sections I-III - Business Needs, Exploration, Preprocessing and Simple Model.ipynb
└── data/
    ├── train.csv
    ├── test.csv
    ├── clientes.csv
    └── sample_submission.csv
```

The notebook reads the data from `../data/`, so the `notebooks` and `data` folders must stay side by side.

## Environment

The notebook uses the course environment (Python 3.13, pandas, numpy, matplotlib, seaborn, scipy, scikit-learn) and kernel. With the kernel installed as a pre-requisite, the notebook should run with no problems.

## How to run

Run all cells from top to bottom. No other step is needed.

## Files created when the notebook runs

Folder : `data/processed/` with the files `test_initial_preprocessed.csv`, `train_initial_preprocessed.csv`
| `submissions/` | `submission_01_logreg_l1.csv` which was used for the Kaggle submission
